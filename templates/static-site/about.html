About this template

Every file is served at its own path

Orbit serves this folder as it is. There's no package.json, so there's nothing to install and nothing to build.

Files

  • index.html, about.htmlthe two pages
  • orbit.cssOrbit's tokens and components
  • styles.cssthis site's layout
  • main.jsthe theme switch and the click counter
  • 404.htmlshown for a path that doesn't exist

Going further

When you want components, a bundler or TypeScript, add a package.json with a build script. Orbit runs it and serves what it writes to dist.
