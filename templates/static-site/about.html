About this template

Orbit serves this folder as it is. There's no package.json, so there's nothing to install and nothing to build: every file is published at the path it has here.

Files

  • index.html and about.html: the two pages.
  • styles.css: the styles both pages share.
  • main.js: the theme switch and the click counter.
  • 404.html: shown for a path that doesn't exist.

Going further

When you want components, a bundler or TypeScript, add a package.json with a build script. Orbit runs it and serves what it writes to dist.
