Every blog starts with a post about starting a blog. This is that post.

It's a SvelteKit app. Each post is a Markdown file in `src/posts`, with a little front matter at the top:

```md
---
title: Hello, world
description: Why this blog exists.
date: 2026-10-01
tags: [meta]
---
```

Add a file, push, and it's published. Set `draft: true` to keep one back.
