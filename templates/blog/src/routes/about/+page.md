# About

This blog is a [SvelteKit](https://svelte.dev/docs/kit) app. Posts are Markdown files in `src/posts`, and this
page is one too: `src/routes/about/+page.md`. [mdsvex](https://mdsvex.pngwn.io) turns Markdown into Svelte
components, so a post can use a component when words aren't enough.

Write something, push it, and it's live.
